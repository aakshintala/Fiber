=== mini harness (macOS arm64 only) ===

Host: Darwin 25.6.0 arm64, Apple M3 Pro, 11 logical CPUs, rustc 1.98.1.
Linux was not measured. Do not treat these timings, RSS, or binary sizes as Linux numbers.
Release binaries; three runs each. Median reported with min alongside (n=3).

SLOC: non-blank, non-comment lines of src/main.rs. A line counts as a comment if,
after strip(), it starts with `//` (covers `//`, `///`, `//!`). No `/* */` in these
files. Counted with a short Python loop over the file.

Crate count: `cargo tree -p <crate> --prefix none --no-dedupe | awk '{print $1}' | sort -u | grep -v '^$' | wc -l`

Thread count at runtime: skipped. `/usr/bin/time -l` on macOS does not report it, and
these crates cannot take the workspace `measure` helper (deps limited to sse_server /
smol / tokio). The programs exit in ~500ms, so sampling `ps` mid-run is not cheap.

Wall time is quoted two ways: `/usr/bin/time -l` `real` (0.01s resolution) and the
program's own `total +<ms>ms` line.

Binary sizes: `cargo build --release`, then `strip` a copy. `stat -f %z`.

Peak RSS: `/usr/bin/time -l` "maximum resident set size". Darwin documents this in bytes.

## async-std maintained? smol HTTP client?

async-std is discontinued. crates.io crate description is now "Deprecated in favor of
`smol`" (https://crates.io/crates/async-std). Latest release 1.13.2 was published
2025-08-15; that publish is the deprecation. The README states "async-std has been
discontinued; use smol instead" (https://github.com/async-rs/async-std). It is not
an actively developed runtime.

smol has no first-party HTTP client. Its own docs show a hand-rolled TCP GET
(https://docs.rs/smol/latest/smol/).

The currently maintained async HTTP client that runs on smol is isahc: runtime-agnostic
(futures-lite, not tokio), latest crates.io release 2.0.1 on 2026-07-05
(https://crates.io/crates/isahc, https://github.com/sagebind/isahc). This workspace
already measures it as `http_isahc`.

surf, the old async-std client, last published 2.3.2 on 2021-11-01
(https://crates.io/crates/surf) and is not maintained. reqwest is maintained but
tokio-only (https://crates.io/crates/reqwest). smol-hyper is a hyper runtime adapter,
not a client, last published 0.1.1 on 2023-12-29 (https://crates.io/crates/smol-hyper).
