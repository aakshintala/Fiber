=== pid/pgid reuse argument ===
macOS ps lstart resolution is 1 second (see raw output above: no sub-second field). The kernel assigns pids/pgids from a rolling counter (PID_MAX ~ 99998 on this system by default), so a pgid number can be reused within a session once the value wraps and the old number is free again. A recorded (pgid, lstart) tuple disambiguates reuse ONLY if the reuse gap exceeds 1 second of wall clock AND no unrelated process happens to start in the exact same second after wraparound -- for a long-running Fiber session doing many kills per minute, that is not a safety margin, it is a birthday-paradox coin flip. The tuple is a heuristic, not a proof.
