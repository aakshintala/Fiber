# Fiber product context

Fiber is an independent native coding-agent product forked from Vercel's fx project. This glossary distinguishes Fiber's product identity from its upstream source.

## Language

**Fiber**:
The independent product developed in this repository. Fiber has its own identity, conventions, state, and release process.
_Avoid_: fx, renamed fx

**fx**:
The active Vercel project from which Fiber was forked. Refer to fx only for upstream attribution or unavoidable historical context.
_Avoid_: old Fiber name, Fiber compatibility name

**native runtime**:
The shipped Fiber executable and its supported process interfaces, with no Node.js, Bun, npm, or JavaScript runtime dependency. JavaScript-based development and test infrastructure is outside this term.
_Avoid_: JavaScript-free repository
